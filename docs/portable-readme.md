# 幻之之 · 使用说明

本文件用于完整安装包，由打包脚本放在包的根目录。

## 启动

支持 Windows 10 / 11（64 位）。将完整包解压到可写目录，双击 `幻之之.exe`。包内已包含 Python 和基础依赖，无需另装 Python；请保留完整目录结构。

点击桌宠打开技能列表，右键打开设置。桌宠隐藏后，可以从系统托盘恢复。

## 使用技能

默认不附带技能。在「技能列表 → 云端」按分类下载安装，或把兼容的完整技能文件夹放入 `tasks/`。安装后在技能列表的「正式」分组选择运行，也可以暂停或停止。云端安装需要联网，已有同名技能不会被覆盖。

创建技能前，在「设置 → AI 设置」配置并启用 Codex 或 OpenCode，再点击「创造新技能」。从两列缩略图卡片中选择窗口，再选择「AI先看看」或「自己说需求」，默认选中「AI先看看」；点击主按钮后才开始分析或进入需求输入，单击或双击窗口卡片都不会启动。建议默认只显示标题和一句简述，点击「展开详情」查看完整要求，点击方案开始创建。不需要应用窗口时选择「无需窗口，直接创建」。先试运行生成的技能，满意后选择「加入正式」。

AI 和技能使用你的用户权限，可能读写文件、执行命令或操作鼠标键盘。草稿目录不是强制沙箱；Codex 使用完整权限且不逐项请求批准，OpenCode 使用自动模式并遵守其显式拒绝规则。请只运行你信任的技能，并先了解 AI 设置中的权限说明。AI 服务可能需要登录或付费。

## 升级与交流

升级前停止技能并退出程序，备份自己的技能、设置和数据。将新包解压到新目录，再迁移兼容的技能。
