# 砖了个砖提示

识别游戏画面，计算消除路线，通过桌宠提示下一步，由玩家操作。技能不读取游戏存档，也不会自动点击或拖动。

## 开始使用

1. 按项目 [快速开始](../../README.md#快速开始) 安装并启动桌宠。
2. 打开一个标题为「砖了个砖」的游戏窗口，进入 14×10 棋盘。
3. 点击桌宠，选择「砖了个砖提示」并开始，无需设置参数。

## 怎样看提示

- 黄色圆圈：要点击或拖动的砖。
- 黄色箭头：拖动方向与终点。
- 紫色圆圈：配对目标。
- 出现多个高亮候选时，按提示点选配对砖。

操作后，技能会核对画面并继续提示。停止任务、隐藏桌宠或提示超时都会撤下指引；停止任务请点击停止按钮。

## 支持范围

目前支持 14×10 棋盘，截图测试覆盖冰蓝色、黄色等皮肤及多种缩放。识别时根据当前画面比较砖面，不需要逐个录入图案模板。

其他棋盘布局、纹理底板和严重遮挡仍有限制。无法可靠区分砖面时会停止并保存诊断；搜索达到预算上限时显示「搜索未完成」并继续观察，不把超时判定为无解。游戏布局变化后会重新搜索。

## 遇到问题

- **等待游戏窗口**：确认窗口标题正确，并且只有一个同名窗口。
- **提示暂时消失**：等待消除动画结束，保持棋盘可见，再查看任务详情。
- **搜索未完成**：当前搜索没有在预算内找到完整路线；不要将提示理解为保证通关。
- **识别失败**：查看 `artifacts/brick_hint/` 下的截图和诊断，再向项目提交问题。
