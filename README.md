# 幻之之

让 AI 做一件事，再把方法整理成可以反复使用的技能。幻之之是承载这些技能的 Windows 桌宠，昵称「之之」。

## 可以做什么

- 飞碟、扫帚两种桌宠主题，支持移动、缩放和状态展示。
- 通过 Codex 或 OpenCode 创建、修改和验证技能；生成结果先进入测试分组。
- 技能在独立 Python 子进程运行，复用宿主 SDK、图像处理和共享组件。
- 支持暂停、停止、运行参数、前台或后台输入，以及互动技能临时接管桌宠。

## 宿主与技能分开维护

本仓库是唯一宿主开发来源，包含 `src/`、宿主测试、构建脚本、文档和许可证。完整包默认不预装技能；公开技能在独立的 `HuanZhiZhi-Skills` 仓库维护。内部技能、游戏截图和私有回归素材不进入宿主或公开技能仓库。

本地 `tasks/` 是已安装技能目录，`test_tasks/` 是待验证技能目录，两者均不受宿主 Git 跟踪。安装时将完整技能目录复制到 `tasks/`，目录须含同名 ID 的 `skill.json`、`task.py` 和必要资源。技能仍依赖宿主，独立仓库不表示可脱离宿主运行。

## 普通用户

Windows 10/11 x64。从 [Releases](https://github.com/huanGrass/HuanZhiZhi/releases) 下载完整包，解压到可写目录，双击 `幻之之.exe`。完整包包含 Python 和基础依赖，无需另装 Python。GitHub 的源码 ZIP 不含运行环境。

本文描述当前待发布版本；已发布旧包的能力和技能格式以对应版本说明为准。

- 点击之之选择技能，状态条显示进度，详情中可暂停、停止或修改。
- 拖动角色移动位置，右键打开设置、调整大小或重启；托盘可以恢复隐藏的桌宠。
- 同时只运行一个技能；退出宿主会停止任务。
- 前台输入会控制真实鼠标；检测到用户接管、窗口失焦或遮挡时会中断。后台输入和桌宠接管是不同能力，技能应按场景选择。

## AI 创建技能

AI 默认关闭。在「设置 → AI 设置」配置 Codex，或通过 OpenCode 引导选择可用的免费视觉模型并完成连接测试。服务登录和费用由用户管理；不启用 AI 也能运行已安装技能。

点击「创造新技能」并描述目标；仅在操作外部应用时选择相应窗口。新建流程先调查并确认实质需求，再进入开发。生成技能保存到 `test_tasks/`，试运行后可转正；修改技能先在草稿验证，保存前检查冲突并备份。停止开发会保留草稿。

AI 和技能使用当前用户权限。草稿写入范围是提示词约定，不是强制文件沙箱；请检查来源和实际行为。结构检查与自动验证不代表体验或所有运行场景已经验证。

## 外部组件

「设置 → 外部组件」检测和安装支持的引擎、模型及运行库，下载内容位于 `dependencies/`，不随基础包附带。组件存在不等于已经安装对应技能。来源与准备方式见 [组件说明](dependencies/README.md)。

## 开发、测试与构建

使用 Windows Python 3.11 x64；准备脚本创建独立运行环境，已有 `python/` 时不要覆盖：

```powershell
python scripts/prepare_python.py
.\python\python.exe -I -X utf8 -m huanzhizhi
```

运行环境、设置、日志、草稿和构建产物不提交 Git。宿主测试使用最小技能样本，不要求安装真实游戏技能。

[开发与发布说明](docs/development.md)包含测试、空技能宿主打包和显式技能包构建方法。接口见[技能开发索引](src/huanzhizhi/skill_creation.md)与[能力参考](docs/capabilities.md)。公共扫雷和围棋代码位于 `src/huanzhizhi/games/`，其更新随宿主发版，不附带对应技能、引擎或模型。

## 升级与反馈

停止技能并退出旧宿主，将新包解压到新目录。先备份自建技能、设置和数据，再逐个安装兼容的技能；旧技能须补齐 `skill.json`。旧 PyInstaller 包需完整升级，不能使用新版单技能更新。当前没有联网自动更新。

日志在 `logs/`，AI 草稿在 `artifacts/`。反馈时提供版本和复现步骤，并检查日志与截图是否含个人信息。
