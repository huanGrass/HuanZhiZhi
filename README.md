# 幻之之

让 AI 做一件事，再把做这件事的方法凝练成脚本，成为可以反复使用的技能。

幻之之是承载这些技能的 Windows 桌宠，昵称「之之」。

<p align="center">
  <img src="src/huanzhizhi/assets/pet_static_tablet.png" alt="幻之之桌宠角色" width="180">
</p>

「幻之之」是「幻之指」的谐音。「指」既是指引，也是自动操作的手指：有些技能给出提示，由你完成操作；有些技能则替你执行具体动作。

这个项目希望把 AI 完成任务时积累的方法留下来，整理成脚本，交给之之调用。下次遇到同样的事情，就能直接使用已有技能。

## 可以做什么

- **桌面交互**：拖动角色、调整大小，通过任务气泡启动或停止技能。
- **过程可见**：查看当前阶段、任务详情和运行日志。
- **扩展技能**：技能以独立 Python 子进程运行，使用统一 SDK 与桌宠交互。

## 快速开始

需要 Windows 和 Python 3.11 或更新版本。程序使用 Windows 窗口截图能力，暂不支持 macOS 或 Linux。

1. 在本仓库页面选择 **Code → Download ZIP**，解压；也可以用 Git 克隆本仓库。
2. 在解压后的项目根目录打开 PowerShell，执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m huanzhizhi
```

首次安装需要下载依赖。保留完整项目目录，并使用上面的可编辑安装方式；技能位于源码目录的 `tasks/` 中。

后续可在项目根目录执行 `./run.ps1`，无控制台启动。若 PowerShell 阻止脚本执行，也可直接使用上面的 `python.exe -m huanzhizhi` 命令启动。

## 基本操作

- 点击桌宠选择技能，通过确认气泡启动。
- 拖动角色调整位置，右键打开设置或调整大小。
- 点击脚底状态条查看详情，点击停止结束当前任务。
- 隐藏后可通过系统托盘恢复桌宠；退出程序会停止任务。

具体技能的使用方式和适用范围见各技能目录中的 README。

## 常见问题

**没有看到桌宠？** 检查系统托盘，可从托盘恢复显示。程序同时只运行一个实例，重复启动时请先检查已有实例。

**去哪里找日志？** 运行日志在 `logs/`，诊断文件在 `artifacts/`。提交问题时先检查截图和日志，再选择与问题相关的内容附上。
