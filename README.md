# 幻之之

让 AI 帮你做事，也把做事的方法留下来。

幻之之是一只 Windows 桌宠，昵称「之之」。

<p align="center">
  <img src="docs/images/zhizhi.png" alt="乘坐飞碟的之之" width="180">
</p>

「幻之之」是「幻之指」的谐音。「指」既是指引，也是帮你操作的手指：有些技能给出提示，有些技能替你执行动作。「之」也让人想到树枝的「枝」——从一个小小的想法开始，在使用和分享中不断开枝散叶，长出更多能力。

这个项目想做的，就是把 AI 完成任务时积累的方法保存成技能。用自然语言描述需求，让 AI 编写，试用、调整后留下来。下次遇到同样的事，直接运行，不必从头再教一遍；也希望大家能分享自己的技能，让之之一起成长。

## 使用方法

支持 Windows 10 / 11（64 位）。下载或克隆本仓库，完整解压后双击 **幻之之.exe**。

首次启动会询问是否安装运行环境，确认后自动下载并显示安装进度，完成后打开桌宠。安装需要联网；以后直接双击即可启动。

启动后，点击桌宠打开技能列表，右键打开设置。在「设置 → 关于幻之之」可查看版本、检查更新、打开下载页、复制 QQ 群号或查看运行日志。

- **创建技能**：在「设置 → AI 设置」中连接 Codex、OpenCode 或 DeepSeek Harness，然后点击「创造新技能」。从两列缩略图卡片中选择窗口，再选择「AI先看看」或「自己说需求」，默认选中「AI先看看」；点击主按钮后才开始分析或进入需求输入，单击或双击窗口卡片都不会启动。建议默认只显示标题和一句简述，点击「展开详情」查看完整要求，点击方案开始创建。不依赖应用的技能可选择「无需窗口，直接创建」。生成后先试运行，满意再保存为正式技能。AI 服务可能需要登录或付费。
- **安装技能**：在「技能列表 → 云端」按分类浏览并安装，也可以将完整技能文件夹放入 `tasks/`。目前提供「砖了个砖提示」和「桌宠排球」，不附带预装技能。
- **导入与分享**：点击技能列表右上角「导入技能」批量选择 ZIP，或直接将 ZIP 拖到桌宠身上；校验通过后加入正式技能，同名不覆盖。在技能编辑页点击「导出技能」即可打包分享。
- **运行技能**：在技能列表中选择技能，运行过程中可以暂停或停止。

技能可能操作你的文件、鼠标和键盘，请只运行你信任的技能。

开发与打包见[开发说明](docs/development.md)，编写技能见[技能开发文档](src/huanzhizhi/skill_creation.md)，制作桌宠主题见[主题制作参考](docs/pet-theme-spec.md)。
