# 幻之之

让 AI 帮你做事，也把做事的方法留下来。

幻之之是一只 Windows 桌宠，昵称「之之」。

<p align="center">
  <img src="docs/images/zhizhi.png" alt="乘坐飞碟的之之" width="180">
</p>

「幻之之」是「幻之指」的谐音。「指」既是指引，也是帮你操作的手指：有些技能给出提示，有些技能替你执行动作。「之」也让人想到树枝的「枝」——从一个小小的想法开始，在使用和分享中不断开枝散叶，长出更多能力。

这个项目想做的，就是把 AI 完成任务时积累的方法保存成技能。用自然语言描述需求，让 AI 编写，试用、调整后留下来。下次遇到同样的事，直接运行，不必从头再教一遍；也希望大家能分享自己的技能，让之之一起成长。

## 使用方法

目前项目仍在开发中，尚未发布安装包，需要从源码运行。

准备 Windows 10 / 11（64 位）和 Python 3.11（64 位）。下载或克隆本仓库，在项目目录打开 PowerShell：

```powershell
python scripts/prepare_python.py
.\python\python.exe -I -X utf8 -m huanzhizhi
```

第一条命令准备运行环境并联网安装依赖，后续启动只需运行第二条。

启动后，点击桌宠打开技能列表，右键打开设置。

- **创建技能**：在「设置 → AI 设置」中连接 Codex 或 OpenCode，然后点击「创造新技能」，描述你的需求。生成后先试运行，满意再保存为正式技能。AI 服务可能需要登录或付费。
- **安装技能**：将完整的技能文件夹放入项目的 `tasks/` 目录。目前不附带预装技能。
- **运行技能**：在技能列表中选择技能，运行过程中可以暂停或停止。

技能可能操作你的文件、鼠标和键盘，请只运行你信任的技能。

开发与打包见[开发说明](docs/development.md)，编写技能见[技能开发文档](src/huanzhizhi/skill_creation.md)。
